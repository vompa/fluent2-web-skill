# Privacy

This plugin contains Markdown instructions (a skill) and nothing else that runs. It does not collect, store or send any data. It has no hooks, no MCP servers, no scripts that Claude runs on your behalf, and it makes no network requests.

`scripts/validate.py` is a maintenance check for contributors to this repository. It reads only the files in this repository and makes no network requests. It is not run when you install or use the skill.

Any data you share with Claude while using the skill is handled according to the terms of the Claude product you use. The author of this plugin receives nothing.

Questions: open an issue at https://github.com/vompa/fluent2-web-skill/issues.
